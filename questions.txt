Q5. Update Book Information

Create:

let books = [
    { id: 1, title: "JavaScript Basics", author: "John", price: 400 },
    { id: 2, title: "Node.js Guide", author: "David", price: 500 }
];

Create:

PUT /api/books/:id

Request:

PUT /api/books/2

Body:

{
    "title": "Advanced Node.js",
    "price": 650
}
Goal

Update only the fields provided in the body.

So the result should be:

{
    "id": 2,
    "title": "Advanced Node.js",
    "author": "David",
    "price": 650
}

Notice that author should remain unchanged.

Q6. Update Course With Validation
Create:
let courses = [
    { id: 1, name: "JavaScript", duration: 3 },
    { id: 2, name: "React", duration: 2 }
];
Create:
PUT /api/courses/:id
Body:
{
    "newDuration": 4
}
Conditions
Find the course using req.params.id.
Get newDuration from req.body.
If course doesn't exist → return 404.
If newDuration is less than 1 → return 400.
Otherwise update the duration.
Return the updated course.

let laptops = [

Create these routes:

DELETE /api/laptops/:id
