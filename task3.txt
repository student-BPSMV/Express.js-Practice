15. Debugging question — very similar to your code ⭐⭐⭐

What is wrong with this middleware?

const validate = (req, res, next) => {

    const name = req.body.name;
    const plan = req.body.plan;

    if (name !== "" && plan !== "") {
        console.log("Valid data");
    }
    else if (name === "" || plan === "") {
        res.json({
            msg: "Invalid data"
        });
    }
    else if (plan !== "Basic" || plan !== "VIP") {
        res.json({
            msg: "Invalid plan"
        });
    }

    next();
};

Hint: There is a logical problem with the condition used for checking "Basic" or "VIP".

The correct logic is:

if (plan !== "Basic" && plan !== "VIP")

not:

if (plan !== "Basic" || plan !== "VIP")

Because with ||, the condition becomes true even when the plan is "Basic" or "VIP".
